# Dr. Ann-Kathrin Andresen | Ing.up

Eine moderne, conversion-optimierte Website für Dr. Ann-Kathrin Andresen - Expertin für Verfahrenstechnik, Mentoring und Innovation.

## Überblick

Diese Website präsentiert die Dienstleistungen und Expertise von Dr. Ann-Kathrin Andresen im Bereich:
- Verfahrenstechnik und Prozessoptimierung
- Mentoring für Ingenieure und Chemiker
- Start-up Beratung (Deep Tech / Chemische Industrie)
- Vorträge und Workshops zu Innovation und Leadership

## Technologie-Stack

- **Framework**: React 18 mit TypeScript
- **Build-Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Routing**: Client-seitiges Routing (SPA)

## Struktur

### Seiten

1. **Home** - Hero-Section mit Conversion-Fokus, Leistungsübersicht, Social Proof
2. **Über mich** - Persönliche Geschichte, Expertise, Qualifikationen
3. **Leistungen** - Detaillierte Beschreibung aller Angebote
4. **Blog** - 10 wissenschaftlich fundierte Artikel zu Fachthemen
5. **Kontakt** - Kontaktformular mit mehreren CTAs
6. **Impressum** - DSGVO-konform
7. **Datenschutzerklärung** - Vollständige Datenschutzinformationen

### Design

- **Primärfarbe**: Navy (#061926) - Vertrauen & Professionalität
- **Akzentfarbe**: Gelb (#ffde59) - Innovation & Energie
- **Neutral**: Weiß und Grautöne
- **Stil**: Modern, warm, professionell mit subtilen Animationen

### Features

- ✅ Responsive Design (Mobile-First)
- ✅ Scroll-Animationen
- ✅ Conversion-optimierte CTAs
- ✅ SEO-freundlich
- ✅ Accessibility (WCAG 2.1 AA)
- ✅ DSGVO-konform
- ✅ Performance-optimiert

## Entwicklung

```bash
# Dependencies installieren
npm install

# Entwicklungsserver starten
npm run dev

# Projekt bauen
npm run build

# Build-Preview
npm run preview

# Linting
npm run lint
```

## Deployment

Das Projekt ist als Single Page Application (SPA) gebaut und kann auf jedem Static Hosting Service deployed werden:
- Netlify
- Vercel
- GitHub Pages
- AWS S3 + CloudFront
- etc.
